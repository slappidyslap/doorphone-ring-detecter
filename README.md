# Doorphone Ring Detector

Система мониторинга вызовов домофона с уведомлением на рабочем столе.
Проект включает в себя прошивку для ESP32 и серверную часть на Java
с графическим интерфейсом в системном трее на Swing.

## Возможности

*   **Автоматическое обнаружение**: Использование mDNS для автоматической регистрации сервиса в локальной сети.
*   **Детектирование паттернов**: Алгоритм фильтрации ложных срабатываний (одиночные шумы, хлопки) за счет отслеживания серии импульсов. По умолчанию 4 импульса в течение 3 секунд.
*   **Сетевое взаимодействие**: Реализация на чистых TCP сокетах без использования протоколов вроде HTTP, MQTT или CoAP.
*   **Мультиплексирование команд**: Поддержка идентификаторов корреляции (`correlationId`) для сопоставления асинхронных ответов с запросами в рамках одного соединения, аналогично механизмам в HTTP/2.
*   **Индикация состояния**: Визуальное отображение статуса соединения через иконку в системном трее: ожидание, подключено, активный вызов.

## Архитектура

Проект разделен на три основных модуля:

1.  **doorphone-core**: Ядро системы. Содержит логику TCP сервера на базе Java NIO (без [Selector](https://docs.oracle.com/javase/8/docs/api/java/nio/channels/Selector.html)), управление сессиями устройств, систему событий и обработчики команд.
2.  **doorphone-tray**: Клиентское приложение для десктопа. Отвечает за работу JmDNS, отображение иконки в трее и вывод системных уведомлений при получении событий от устройства. Использует модуль `doorphone-core`, как либу.
3.  **firmware-esp32-arduino**: Прошивка для микроконтроллера ESP32-S3. Реализует считывание сигналов с цифрового входа (например, датчик звука KY-038) и передачу событий на сервер.

## Протокол взаимодействия

Взаимодействие между устройством и сервером происходит через TCP сокет с использованием собственного текстового протокола. Для поддержки асинхронности используется механизм мультиплексирование.

### Формат сообщений
*   **Команды (Сервер -> Устройство)**: `C:<correlationId>:<command_name>`
    Пример: `C:42:PING`
*   **Ответы (Устройство -> Сервер)**: `R:<correlationId>:<payload>`
    Пример: `R:42:PONG`
*   **События (Устройство -> Сервер)**: `E:<event_name>`
    Пример: `E:RING`

## Алгоритм детектирования звонка домофона

Для минимизации ложных срабатываний используется логика окна времени:
1. При поступлении первого импульса открывается окно `RING_WINDOW_MS` (по умолчанию 3000 мс).
2. Система подсчитывает количество импульсов.
3. Событие `E:RING` отправляется только при достижении `RING_COUNT_REQUIRED` (по умолчанию 4 раза)
внутри окна `RING_WINDOW_MS`.
4. После срабатывания активируется `RING_COOLDOWN_MS` (по умолчанию 5000 мс) для предотвращения повторных уведомлений
от одного вызова.

## Настройка и запуск приложения

### Сборка Java модулей
Требуется JDK 21 или выше и Gradle 8.4 или выше.
```bash
./gradlew build
```
Запуск трей приложения из терминала из корня проекта:
```bash
java -jar ./doorphone-tray/build/libs/doorphone-tray-<version>-all.jar
```

### Прошивка устройства
1. Откройте проект в `firmware-esp32-arduino/doorphone-ring-detector-esp32s3`.
2. В файле прошивки укажите параметры Wi-Fi (SSID, Password).
3. Загрузите код в ESP32-S3 через Arduino IDE или PlatformIO.
